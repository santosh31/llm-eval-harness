# LLM Evaluation Harness

## What This Evaluates
An LLM-based **text summarizer**: input = a long-form article/document,
output = a shorter summary preserving key information.

## In Scope
- Single-document, single-turn summarization
- Faithfulness (no invented facts), relevance (key points covered),
  conciseness (length-constrained), fluency/coherence

## Out of Scope (for now)
- Multi-document / multilingual summarization
- Real-time or streaming evaluation
